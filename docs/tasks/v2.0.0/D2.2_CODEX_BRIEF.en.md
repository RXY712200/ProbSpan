## 3. Exact scientific contract

The estimand is the common Bernoulli success probability p of independent, identically defined binary event observations at a FIXED sample size n (same outcome, unit and observation horizon). Such inputs are caller assertions; the library does not authenticate independence, sampling, non-overlap or external validity.

Single entry point (public design requirement; choose conventional concrete public enum/type spelling consistently):
  ps2_binomial_interval(method, events, n, alpha, sidedness, out)

- method selects Wilson or Clopper–Pearson. Every result names the selected method and the nominal alpha and sidedness.
- events and n are uint64_t, 0 <= events <= n, support 1 <= n <= 1,000,000. n == 0 reports EMPTY, not a prior estimate. Inconsistent counts are invalid; unsupported n must be rejected before any overflow-prone computation.
- alpha is finite and initially supported in [1e-10, 0.5]. Out-of-declared-support values are UNSUPPORTED; NaN/infinity/invalid alpha and invalid enums/pointers are INVALID_ARGUMENT. Define a stable, documented validation/error precedence consistent with the D1 plan (pointer and enum validity, data/domain, then numerical work).
- sidedness includes TWO_SIDED, LOWER_ONE_SIDED and UPPER_ONE_SIDED. Two-sided tail = alpha/2; one-sided tail = alpha. Two-sided result is [L,U]. Lower one-sided is [L,1], upper one-sided is [0,U]; unconstrained end MUST be exactly 0 or 1, as applicable.
- Wilson: invert the score quadratic using z = Phi^{-1}(1-tail). This is a confidence interval with approximate, not universally nominal-finite-n, coverage. Use a stable formula for zero counts, full successes, very small tails and small n; avoid subtractive cancellation and spurious out-of-range endpoints. Explicitly distinguish Wilson from exact CP in results/docs.
- Clopper–Pearson: for interior 0<k<n, L is Beta(k,n-k+1) tail quantile; U is Beta(k+1,n-k) (1-tail) quantile. Equivalently, solve Pr_p(X >= k)=tail for L and Pr_p(X <= k)=tail for U. Boundaries k=0 give exact L=0; k=n give exact U=1. Implement all one-sided boundary variants correctly. A one-sided zero-success upper bound is -expm1(log(alpha)/n), and the two-sided analogue uses alpha/2; complement symmetry may be used but must not silently reverse tail direction. For n=10,k=0, one-sided 95% upper bound is about 0.258866.
- CP's mathematical fixed-n coverage is at least nominal under its stated assumptions; a floating endpoint rounded inward can invalidate a claim of strict outward exact-tail coverage. Do not present a nearby answer as certified outward unless it is demonstrably on the safe side of the exact root, including when the root falls between adjacent binary64 encodings.
- Repeated peeking, optional stopping, duplicated observations and changes in endpoint or population violate the fixed-n iid contract. No confidence-sequence or sequential guarantee.
- No Bayesian posterior, Jeffreys prior, odds/EV, source borrowing, calibration or historical-readiness gate applies to this F001 operation.
