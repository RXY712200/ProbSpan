## 1. Mission and hard scope

Implement V2-F005: a deterministic, fixed-archive, common-denominator, **paired** evaluator for two binary probabilistic forecasts A and B in the separately installable ProbSpanModels 2.0.0 C11 static library.

Each row represents a caller-admitted unique request/target unit in the same frozen evaluation cohort and a fixed truth revision. The evaluator supports a pair of independently optional forecast values, an optionally available binary truth, integer release/deadline/realization/truth-availability ticks, fixed nonnegative row weight, and a nominal evaluation cutoff. It computes two proper scoring rules:
- Brier loss: (p-y)^2, finite even for wrong-certain forecasts.
- Bernoulli log loss: -log(p) for y=1, -log1p(-p) for y=0, with *exact* binary64 0/1 wrong-certain values producing mathematically infinite loss; do not clip, cap or pretend a near-endpoint finite p is the same as 0/1.

For each score, use one common eligibility mask and the SAME strictly positive weight denominator to calculate A, B and paired difference A-B. Include audit counters and weight sums that make exclusions, unanswered forecasts and delayed/unknown truth visible. Handle one-sided infinity, both-sided infinity and absent common positive weight with explicit result states; never force a winner, a significance test or calibration certificate.

D3.3 is the FINAL implementation unit of D3, **not** permission to start D4, a Preview or any release process. Do not implement F006 cross-source borrowing, a prediction service, data ingestion, forecast generation, train/test splitting, automatic duplicate detection, truth-provider authentication, causal analysis, portfolio returns, betting EV, confidence sequences, optional-stopping significance, clustering inference or generalized evaluators. Do not alter accepted F001–F004 algorithms. Preserve existing independent legacy ProbSpan 1.1.0 package, Models version 2.0.0 and ABI generation 1.

## 4. Exact endpoint/infinity/empty rules and examples

For finite p and binary y, Brier=(p-y)^2. For log:
- y=1, p=0 => +infinity; y=0, p=1 => +infinity.
- y=1, p=1 and y=0, p=0 => EXACT zero log loss; do not generate a NaN from multiplying zeros or evaluating log(0) on the correct branch.
- Every representable p strictly inside (0,1) has finite log loss; p=minimum positive subnormal eta, and p=nextafter(1,0) are finite and MUST NOT be clipped to endpoint/marked infinite. Use -log(p) or -log1p(-p) with branch-specific numerical care.
- Zero-weight rows skip scoring entirely, even if p/y would have yielded an infinite log loss. No floating multiply 0*INFINITY.
- If A log loss +infinite and B finite, paired A-B=+infinity. If B infinite and A finite, paired A-B=-infinity. If BOTH have +infinite loss, paired difference is UNDEFINED, not +0 or NaN silently compared. Both individual infinite states are still reported. Distinguish no finite aggregate, mixed finite/infinite, paired-inf and both-inf states with explicit types. Per-model Brier remains finite on valid input in these cases.
- If there is no common positive-weight scored row, return an audit-only result with NO readable scores or differences; do not divide by zero or invent a tie. Preserve output atomicity on actual errors.
- The finite-score difference must come from compensated signed PER-ROW differences, with a shared positive W, not from subtracting two already rounded means and pretending cancellation is reliable. If its certified numerical envelope straddles zero, report uncertain sign/direction. Do not invent a universal epsilon, "winner" or p-value. An exactly zero mathematical difference must not be misrepresented as significant.
- p=.8, y=1 gives Brier .04 and log -log(.8). Reproduce frozen-A (.8,.8,.2,.2), B (.4,.4,.6,.6) with initial truth (0,0,1,1), then revised truth (1,1,0,0): ranking reverses under revision, demonstrating why the truth version must be held fixed for a reported estimate. Demonstrate the difference between zero response rate and conditional-only score using an explicit pair-mask/abstention example.
- Include delayed label/realization, already issued but unfulfilled requests, both answers absent, exactly one answer, two wrong-certain predictors, wrong-certain only on zero-weight rows, p close to 0/1, and row ordering/permutation.

Avoid explicit NaN/inf values where result state should encode missing/undefined; use an exact tagged state and document whether a numeric field is readable when its corresponding state says unscored/infinite. Never let one metric's infinity accidentally wipe out the other metric's valid results. Output must be fully initialized and unchanged BYTE-FOR-BYTE for all failures. An audit-only success is a success, not a corrupted estimate.

## 5. Numerical qualification gate (no green-CI shortcut)

The D1 plan specifies a **candidate error decomposition**, not an approved global tolerance:

For each finite weighted score on the same strictly positive W, propose and justify
  E <= (sum_i w_i * e_leaf_i + E_sum) / W + E_div,
where e_leaf_i accounts for binary64 arithmetic, appropriately bounded platform log/log1p error and weight operation, E_sum bounds compensated accumulation error, and E_div covers denominator accuracy and final division. Preserve units, signs and input binary64 exact encodings. Treat weighted numerator and W as distinct. A proposed blanket 1e-10 threshold or max observed error presented as a theorem is NOT acceptable.

All score and difference budgets MUST be predeclared by output and domain and independently challenged:
- For Brier, compute exact Fraction values of each encoded p, weight and binary y, shared eligibility masks, audit weight sums and finite aggregate. For difference of Brier, exact signed rational row differences provide an independent oracle.
- For log, use independently implemented high-precision log/log1p references at at least two precision tiers equivalent to >=80/160 bits (or higher). Keep an exact rational check of which branch is zero, strictly finite or infinite. Compare finite leaf losses, per-model means and paired signed differences in absolute and relative units where appropriate.
- Freeze hard cases: p in {0, eta, minimum normal, 0.5, nextafter(1,0), 1} with both labels; weights {0,2^-40,1} and neighbors; lengths including 0,1,2,100,10000,1000000 as practical; timestamps exactly at/one tick around the inequalities; delayed and revised truth; model A/B presence combinations; mostly canceled signed differences; one-sided/both infinity; tiny Brier weighted contributions that round to 0.
