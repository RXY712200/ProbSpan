## 最小可结束的候选

1. **进入条件**。拥有者选择一个明确的场景与负责人，提供有合法访问权限的已成熟固定期对象、代表性失败/缺支持场景、由域审查者标记的对照和可见 cutoff。预先定义接受/拒绝占比、误纳/误拒成本和允许延迟，按簇与时间切分；没有这些条件则保留现状和合成参考。
2. **资格与调用闭环**。先与已有设备 Preview 和直接 caller 基线对照。只有出现真实重复错误且合同相同，才补必要的外部检查或时间/版本约束。纯 C 继续处理同义计数。使用明确快照和输入值补丁，不能以新 prior 隐藏适用问题。边界状态重放一致、未成熟期/源冲突/依赖/空支持无误入，直连与适配等价的合格例可逐字段查明。不可验证的假设保留未知。
3. **退出条件**。独立审查在预先批准评估集和目标权/窗口下比较误纳、误拒、弃权和全请求损失的不确定范围；在兼容环境用旧消费者和数值参考回归。若无法证明实际净收益、已有参考足够、或必须破坏合同，则停止推进并保留可审查结果。单个统计工具失败与领域资格失败分别报告。无必要时不新增组件。

## 有依据时可以比较的扩展

若外部试点显示同一清晰目标既需要合法分层权结果、又需要报出不同含义的参数区间，先在独立工具比较既有固定两层与扩展情况，保留已知权、权共估及空层反例。证据需明确权来源、联合抽样、独立参考和不可计算的数值预算，决策入口另审。可用现有参考或单独分析；根没有此依赖。若又出现独立第二 C 计算消费者，可单独考察共享私有 Beta 叶节点。两项没有必要绑定，独立求值失败或缺数值精度时可先退回各自路径。真值评价作为外部配对任务另取输入，可独立停止，无需改任何旧 estimator。 [B-E003](../phase-b/experiments-and-results.zh-CN.md#b-e003) · [B-E006](../phase-b/experiments-and-results.zh-CN.md#b-e006)

## 验证与可选的发行门槛

进入编码前固定估计对象、域条件、安全拒绝行为、独立真值和预算、旧兼容责任及范围。完成后给出实际 diff、数值/科学/兼容分别的测试结果与独立 review。若后续确有用户授权进入候选或稳定发行，须以精确提交对照旧消费者、产物依赖及许可证、所声明平台、数值及数据证据，并接受独立评估。通过步骤没有自动发布含义。缺失的工程证据包括更多工具链/浮点模式；缺失的科学证据包括真实固定期设备的代表性、跨群验证、用过的目标权/代价及真实评价 vintage。
