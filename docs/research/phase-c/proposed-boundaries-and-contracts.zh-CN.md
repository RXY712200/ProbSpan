# 条件蓝图与语义合同草案

[导航](README.zh-CN.md) · [整体方案](architecture-alternatives.zh-CN.md) · [风险和验证](integration-risks-and-validation.zh-CN.md)

设计符号只描述何处交付事实和值，全部待审。最小方案只在有实地使用需求时添加外部的有界接入。现有 Preview 已展示类似单向配置，是对照。

```text
Caller owns endpoint, time and immutable evidence
  |                                      |
as-of observations + declaration      issued forecast archive
  |                                      |
optional domain admissibility          external evaluation <- paired truth vintage
  |                                      |
eligible mature counts                score/report
  |
installed v1 C API -> typed history + decision result

Other optional model <- its own admissible inputs and target
  |
model-specific result -> applicable external decision
```

上游将已完成的检查交给下游公开边界，C 核心无需回调资格审查或访问存储。可选装置可先复用 `review`、独立进程协议及安装的 `history_estimate`。同义计数才跨到该 API。如果未来支持其他分布，独立保留其输入、结果和决策语义。外部评价程序只读预报/标签配对快照。

| 交接对象 | 最少信息与检查责任 |
|---|---|
| 观察快照 | 参考总体及纳排、稳定观测键及命名空间、单位、端点定义/修订、窗口与时距、预测时点可见 cutoff、最终成熟规则、原始值及来源/工况。机械检查字段、时点、同义性、冲突及已给的组信息；潜在依赖和可迁移性由提供者及审查者论证。 |
| 准入收据 | 实际采用的快照标识、机械检查、调用方声明/引用、未知事实、理由及版本；符合时附 e/c 或该模型所需的非计数输入。可重放须能访问同一快照；声明和检查分别显示。JSON 不充当认证凭证。 |
| 二元参数／调用结果 | 端点和目标由调用方关联；v1 输入 e/c、模型/gate 和 readiness、后验均值与中央可信区间、字段可用性保留。不同模型分别提供组级、目标权标准化、部分识别集或预测分布。 |
| 决策及比较 | 同一事件、互补和支付单位；保持 v1 odds/EV/epsilon 及版本。只对齐语义相容的决定，保留冲突；其它效用或弃权成本由外部定义。 |
| 评价包 | 发出预测 ID、信息集时间和真实发出值，配对兑现及其版本、组/时距、缺失及 abstention 掩码、权重、监测协议。可以重算同一分母的分数，未来技能和部署选择仍需新证据。 |

## 状态、传播和时序

| 事实 | 路径及输出约束 |
|---|---|
| 结构/API 无效、版本错或求值失效 | 保留错误和具体原因，无该次结果。v1 非 OK 不改输出，调用者须先读状态；历史成功输出可保留供回溯。 |
| 端点冲突、不完整、来源未证实、已知依赖 | 外层拒绝/条件/未知，保留观察事实且不给合格计数。不要把资格失败改写为 (0,0)。 |
| 合格但没有样本；合格但 n 或宽度不足 | 空为 NO_HISTORY；稀疏可有区间但 readiness=false，历史 EV 不可用。独立主观结果仍可用其自身合法输入计算，关系返回历史不可用。 |
| 缺支持、选择性观测、目标不识别 | 域外可注明额外假设或给界，保持推断类型和出处；界没有默认后验概率质量。 |
| 两模型可比较但意见冲突 | 保留两侧估计、分类和 provenance；允许外部查明重复信息，没有自动融合动作。 |
| 同一结局修订或无标签 | 评分方固定规则、版本、分母和缺失掩码；旧分析仍可以重放。按声明任务拒绝不完整配对或报告覆盖。 |

调用者报告真正的展示/获知与 raw 改变顺序。现行 `provenance_transition` 不把版本变化当成暴露，也不能鉴别资料可靠性。存储采用版本化快照和字段，保留原赔率编码、模型/gate/分析版本及相应工况。未知版本拒绝重放或仅显示持久的历史结果。 [API 持久与重放](../../API.md#persistence-and-replay) · [信息合同](../../PROVENANCE.md)

## 对抗走查（设计推演）

| 情景 | 传播路径和停点 |
|---|---|
| 借用有效／冲突 | 同任务共同 p、合格独立数据及领域论证均成立时，计数可加并用旧模型。若同 p 未获支持，走目标历史或 unknown；后来观察到冲突要重新审查声明。空目标时宽混合不能自适应，条件先验输出仍要显式声明。 |
| 别名、真重复、删失 | 同设备/周期一致的两个 query 可为别名；同主体不同周期或同簇是真观察但可能相关，进簇分析或拒绝计数。观察至第 50 小时未失败时，100 小时补事件未成熟；进入风险集任务。 |
| 条件预测、历史率与得分 | 特征预测条件是 Xₜ，历史率在声明总体边际化 X，评分是配对记录的损失。各自保留人群和评价时距，三个数值相同也不得写入同一个 history_result。 |
| 参数尾与下一次 | 风险后验集中在 .4，odds=2 时正 EV 参数尾可接近 0，下一事件仍约 .4；区间跨阈值和 Brier 分开。 |
| 表示误差 | 两个分别略低、高于 2 的十进制文字映为相同赔率，旧规则以该编码和原次序产生一致尾结果。额外精度要不同对象/预算；数值容差与政策状态各检查。 |
| 真值与选择 | 回填较晚结果时保留首版和终版评价，旧预测冻结。只有部分行动后标签，报告观测掩码与条件界；只报子集分数不能表达全请求成本。 |
| 新增 survival 方法 | 外部读取完整时点与原因，独立返回 CIF。根无需风险集、新 gate 或组合器变化；独立数值/估计量测试走外部。可选工具移除时原安装和存档照常。 |
