# 问题、估计量与可观测性

[导航](README.zh-CN.md) · [Phase A 52 项交叉表](../phase-a/ledger-crosswalk.zh-CN.md) · [永久账本](../../TECHNICAL_DEBT.zh-CN.md) · [Phase A 新问题](../phase-a/new-questions-and-gaps.zh-CN.md)

时间线以预测起点 t 为界。兑现历史只使用 t 时已成熟的同义观察。特征训练材料还需当时可见的 X 与随后兑现的 Y。预测表现历史则需归档 t 时实际发布的分布、目标/时距和随后匹配的兑现版本。三类数据给出的信息和抽样单位不同。下表的“可识别”均指理想总体观察分布在所列领域假设下的性质；有限数据另有估计误差。没有明确事件/单位/时距时，表中给的是应定义的对象而非补造产品默认值。

| ID | 问题、总体/单位/时距、可用输入 | 识别与不确定性；同目标对照或不可比原因 |
|---|---|---|
| A01 | 指定稳定总体的一次完整独立单位、固定 h，已成熟事件/补事件计数 | 条件 iid 给风险 p；v1 计数基线 B-E001。领域端点与独立性不由两个计数推出。 |
| A02 | 同一 p，t 时只看到少量或零目标单位 | p 属模型参数；空样本不更新先验。比较宽度、覆盖与可用率 B-E001/B-E002。 |
| A03 | 未来一次性事件 h 内结果；t 时可有特征或专家信念 | 无参考类或结构时风险不识别；比较同题预测过程，不能把缺历史误读为均匀概率。 |
| A04 | 异质事件的定期预测表现，单位为事件簇与预报时距 | 预测归档和成熟真值可识别该评价总体的评分均值，未来校准依赖稳定性。B-E005。 |
| A05 | 仅事件名字、无支持证据 | 所有 p 与输入相容，识别集 [0,1]；弃权。 |
| A06 | t 时给定主观信念，固定 logit 宽度映射 | 映射是确定量；经验概率未经识别，用已归档同任务预测评估。 |
| A07 | 稳定总体风险，只需计数、无赔率/主观输入 | p 的估计可独立于结算；v1 Jeffreys 与参数区间 B-E001。 |
| A08 | 给定 t、单位及 h，区分二元、次数、时间和连续阈值对象 | 特征和训练单位决定所需数据；不能统排不同输出。 |
| B09 | 同主体变更后的 h 风险，只有旧工况已兑现历史 | 变更后的条件风险缺目标标签时不识别；条件借用对照 B-E002。 |
| B10 | 不同主体的同义风险或新组风险 | 要证实共享 p 或条件交换性；完全池化与组级风险目标不同，比较其对同一目标的预测 B-E002/B-E007。 |
| B11 | 目标域 h 风险；t 时可能只有目标 X 和源 X,Y | 机制不变且正性时可标准化；机制变可构造观察等价。B-E003。 |
| B12 | 无关历史对目标风险 | 无桥接约束不能识别；不借/未知，不把权重调小当证据。 |
| B13 | 同单位不同标签或观察窗 | 只能从可复验原记录重标；少于 h 的随访缺标签；B-E004。 |
| B14 | 适用性未知的目标；输入含声明/出处，缺检验证据 | 数学上可给敏感性或界，不能从数值相似度识别机制。B-E002/B-E003。 |
| B15 | 同任务多组历史，新/小组 p | Beta 超参数估计依赖组总体和组数，EB 忽略超参不确定；B-E007 检查已见组。 |
| B16 | 条件可交换组分布和既有/新组 p | 层级似然和超先验联合；未见组需外留组测试；B-E007 是已见成员。 |
| B17 | 目标 p，历史机制可偏移，n 小 | 比较不借、折扣和混合，同目标真值下固定来源条件；空目标无法自适应。B-E002。 |
| B18 | 固定目标构成、单位层 X 的风险 Σwₕpₕ | 层内机制稳定、目标权已知或估计；粗率属抽样混合。B-E003。 |
| B19 | 已知主体/簇，多行共享潜因 | 均值与方差需要不同层级处理；可观测簇结构下比较按行和簇。B-E003。 |
| B20 | 同单位、同查询重叠及版本修订 | 缺事件身份无法识别重复量；重放和样本独立为两件事，B-E003 的完全同簇为方差极端。 |
| B21 | 抽样构成或选择发生变化 | 正性与条件选择机制支持识别；未知选择及空层给界。B-E003/B-E005。 |
| C22 | 专家对同一 t 信息集的目标分布及判断能力 | 评分需要兑现题并保留共享信息；主观规则宽度不能充作心理测量。 |
| C23 | 新组参考分布，少量或空目标观察 | 先验预测提供条件于参考群的信念；与空数据弃权对照 B-E002。 |
| C24 | t 后新数据加入的同一 p | 先验×独立新似然，重复资料需共同似然/去重；混合证据权 B-E002。 |
| C25 | 具有可用 X 的个体风险 P(Yₜ₊ₕ=1∣Xₜ) | 需带时序特征与标签及支持；按实体/时间留出对比常数，二元聚合计数不能恢复条件风险。 |
| C26 | t 时预测分数映射到兑现概率 | 在验证人群内可估，样本外受漂移；独立校准集及原预测为基线。B-E005 给失败反例。 |
| C27 | 连续分布超过给定阈值的预测概率 | 需要同一 horizon 的 CDF 或样本，点质量决定 ≥/> 区别，参数后验概率另列。 |
| C28 | 给定模拟模型的风险与现场目标风险 | 模拟误差可测，实地偏差要真实兑现；B-E001–006 的构造不得当现场样本。 |
| C29 | 同题同日多来源预测分布 | 同题配对可比较单项、等权等，但未知共同信息不识别最优融合或联合似然。 |
| C30 | 同时窗两事件联合/CDF 或条件概率 | 仅边际给 Fréchet 界；满足 p_B>0 方可定义条件风险，需联合记录。 |
| C31 | 连续新结果分布与预测区间 | 给已兑现连续 Y 与信息集才可评 WIS/CRPS；与 p 区间不可通约。 |
| C32 | 每单位暴露率 λ、未来区间计数、至少一次事件 | Poisson 在确定暴露与独立增量下连接这些量；过度离散或复发要事件级记录。 |
| C33 | 指定 h 的生存/按原因累积发生 | 事件时点、风险集、失访条件；1−KM 和 AJ 对象不同。B-E004。 |
| C34 | 未来时距条件风险或时间序列分布 | 仅用 t 当时数据滚动；时期可变时固定参数模型未知。季节朴素或常数可比较于同目标。 |
| D35 | 同题配对期望损失及差值 | 依赖预测存档、结果版本、事件簇和覆盖；时间连续窥视改变错误。B-E005/B-E007。 |
| D36 | t,h、群体内可靠性 P(Y=1∣forecast,group) | 只有边际校准不够；子组和时距报告不确定。B-E005。 |
| D37 | 就绪 gate 相对于目标适用性 | gate 由 n 与宽度确定；适用性需要域证据，可有 READY 却错对象。B-E001/B-E002。 |
| D38 | 信息实际曝光、来源依赖和结果修订 | 状态映射可复核，真实源事实、遗漏或先前阅读不能从状态反推。 |
| D39 | 参数、预测结果、主观规则及数值边界 | 区间对象必须先定；频率比较仅对固定 p 设计。B-E001/B-E006。 |
| D40 | 机制漂移后同 h 风险，目标标签延迟 | 没有目标标签时边际变化不足，分段/不转移与 roll-forward 基线。B-E002/B-E005。 |
| D41 | 极少或零事件的 p 和罕见尾 | 0/e 与完全没数据不同；单侧界、后验量及二侧覆盖各有意义。B-E001/B-E006。 |
| D42 | 给定结算和 h 的期望效用、最优行动、弃权 | 需损失、成本与共同后果；参数越阈值概率与下次中奖概率不同。B-E002/B-E005/B-E006。 |
| D43 | 相同目标上两路概率及其冲突 | v1 比较状态是确定规则；不能推出联合信念，先查信息依赖及端点。 |
| D44 | 单个结果与预测者校准 | 一次兑现只产生一次评分；同观测可由多概率产生。要预测—兑现系列。 |
| E45 | 提取截至 t 的合法独立事件计数 | 需要原消息粒度、版本与选择/去重保证；数据库只实现查询，非统计识别。 |
| E46 | 不同模型结果对象是否可替换 | 估计量、条件及不可用含义不同，不能从统一函数签名推出数学同一性。 |
| E47 | 当时快照、输出重放和跨版本意义 | 持久日志与环境可复算，缺历史版本无法重建当时可得信息。B-E005。 |
| E48 | CDF/PPF 数值、舍入及状态 | 固定数学参数编码与容差核对，跨平台证据仍缺。B-E006。 |
| NEW-A-001 | 同一预测发出日、两真值 vintage 对应损失 | 样本配对和评价对象版本决定比较；B-E005 排名可变。 |
| NEW-A-002 | 行动改变哪些结局可见或可发生 | 部分识别或需随机验证/因果假设，不能只用完成病例；B-E005。 |
| NEW-A-003 | 重复观察预测差时的显著性/序列置信 | 事先规定时间范围和 filtration，独立符号过程可精确对照；B-E005。 |
| NEW-A-004 | 同名端点在设备/组间误标 | 已知 Se/Sp 且可迁移时反演，否则观察等价；B-E004 与独立解析。 |
| NEW-A-005 | 层权和风险共享数据时的误差 | 联合估计方差含协方差；缺支持时给界而非方差修补。B-E003。 |
| NEW-A-006 | 十进制输入、binary64 倒数和政策边界 | 同 CDF 参数做数值核对；原精确赔率语义另计。B-E006。 |
| NEW-A-007 | 全请求的预测/弃权成本和选择性评分 | 已预测子集分数、覆盖和代价各异；同总体策略比较 B-E002/B-E005。 |
