# Preview 研究：历史概率模型比较与数学验证

这是三个主要工作单元中的第二个，属于 Preview 研究。结论为待独立审核的建议，尚无产品模型、版本或发布决定。已接受的 [Phase I 证据框架](HISTORICAL_EVIDENCE_RESEARCH.zh-CN.md) 对应 main `a344e6c01d821f5d45608cb1a7c0d6655b897ada`。本实验在同一文件树的本地 HEAD `a9e9e7ae76d05e81a3e42d8d898c34a5f0d528e0` 运行。Stable `v1.0.0` 源码仍为 `fdfaddfb58486004ee1cc02c0f4a5c640cd17c7c`。

## 结论与下一步边界

下一工作单元的设计审查建议只推进**严格目标历史、显式证据准入，以及调用方的分层目标风险**。共同参数确有证据时，合并合格计数仍可使用现有 v1 路径。已知层风险不同而目标权重可信时，优先用外部标准化，评估是否需要独立的结果类型。没有适用证据、目标层无支持或上下文未知时保留弃权。经验 Bayes、分层 Bayes 和稳健借用保留为外部对照。不能凭名称、相似率、窄区间或零目标观察时的先验当作纳入证据。待所有者确定实际端点、数据权属、风险阈值、弃权成本和最小可接受验证场景后，才有下一单元的设计输入。

## 数学对象和比较条件

目标是下一完整 100 小时周期内发生定义指定故障的概率 `q = Σ_h w_h p_h`。固定目标权重 `w_h`，用层内同一目标机制的风险 `p_h`，对未知参数作中央 95% 后验区间；下一新单位的预测分布为 Bernoulli(后验均值 q)。多次未来结果若共用同一潜在风险，样本计数的预测分布是 Binomial 条件分布的混合；等概率条件下方差为 `m E[q(1−q)] + m² Var(q)`。该计数预测区间没有在本实验测量。目标权重在真实任务可能还有抽样误差或与层风险相关，应联合传播。实验按已知固定权重以及层参数独立作对照。

| 方法 | 似然、先验、估计及适用条件 | 区间含义及计算成本 |
|---|---|---|
| 严格历史 | 目标独立同分布 Bernoulli，Jeffreys Beta(½,½)。见 e 个事件、n−e 个补事件后，`p given data ~ Beta(e+½,n−e+½)`。零记录弃权；已声明层异质时聚合二项似然不成立，用目标分层对照 | 解析均值、两个 Beta 反 CDF。实验只比较估计，v1 的实际决策还须符合冻结 gate |
| 声明可比队列池化 | 相同事件、观察单位、已支持同一 p 且观测独立才合并来源及目标计数。共同参数强于可交换组参数 | 仍是 Beta；成本主要是记录审核。已知异质时置信度集中在错误对象 |
| 分层标准化 | 每层独立 Jeffreys 后验，层内源/目标风险相同才合并，按目标权重求后验均值。若层内组风险不共享，不能简单累加；目标分层对照完全不用来源 | 独立抽样各层 `q^(s) = Σ w_h p_h^(s)`，取 q 的分位数。已知固定权重且独立层时 `Var(q)=Σw_h²Var(p_h)`。不可直接加权层分位数。时间 O(H×抽样数) |
| EB | 给定 p_j 时，组事件数 Y_j 服从 Binomial(n_j,p_j)，且 p_j 服从 Beta(μκ,(1−μ)κ)。来源独立组拟合边际似然，选择有限网格最大值，目标更新固定超参数 | 对群体分布的估计误差不传播。网格上界命中、少组或不均衡组可产生过度收缩。时间 O(H×组数×网格点+H×抽样数) |
| 层级 Bayes | 同上，`μ, log κ` 等权离散网格先验；来源和目标均更新超参数，新的目标组只在似然中出现一次。每层独立 | 混合不同超参数条件下的目标 Beta 后验，传播超参数误差。有限网格是参考近似，边界及先验需要敏感性分析。同阶网格计算，并额外计算归一化权重及抽样 |
| 稳健借用 | 每层强成分为来源 Jeffreys 均值 m 与限制强度 `c=min(20,n_source)` 构成的 Beta(mc,(1−m)c)。混入权重 0.2 的 Jeffreys；条件独立的目标计数更新。它是带弱成分的限强度参考，未拟合真正 MAP | 传播混合成分而忽略来源中心的估计误差。时间 O(H×抽样数) 与两个更新项；增大 cap 或减弱弱成分可提高错误转移风险 |

EB/层级的组边际似然省略与超参数无关的二项系数，乘积因子为 `B(a+e_j,b+n_j−e_j)/B(a,b)`。弱成分和其他成分同样依据该比值更新权重，采用 log-Beta 和 logsumexp；零目标记录时比值均为一，权重没有冲突反馈。分层和混合区间使用确定种子的随机近似，均值按公式计算。数值求解本身与 v1 C 中普通/大计数 Beta 路径及浮点契约独立。

### 理论、外部经验和独立计算

- [Dahabreh 等，Epidemiology 2020](https://pmc.ncbi.nlm.nih.gov/articles/PMC9066547/) 以 HALT-C 演示目标协变量标准化/加权和敏感性。其对象是因果效应，此处比较描述性风险；借鉴识别条件，即一致定义、条件风险可传递、目标支持为正及正确目标权。单有协变量重叠不能识别隐藏机制变化，早期选择依赖结局时通常还需选择机制。
- [Efron 与 Morris 1975](https://doi.org/10.1080/01621459.1975.10479864) 的棒球收缩例提供真实对照，[Stan 的复现教程](https://mc-stan.org/learn-stan/case-studies/pool-binary-trials.html) 用初期打数拟合、赛季后段打数预测，并区分组参数与新计数。后段仍属已见球员，不能证明未见组外推。这里用合成的未见目标主体检验迁移，固定共享场景及随机目标风险场景分别报告。
- [Schmidli 等 2014](https://doi.org/10.1111/biom.12242) 演示历史对照 MAP 和弱成分，对特定临床设计报告操作特性。[RBesT 二元案例](https://opensource.nibr.com/RBesT/articles/introduction.html) 用 gMAP/Stan MCMC 表示试验间异质性和新试验预测，robustify 加弱成分。本文实验省略 MCMC 和 MAP 拟合，因主要问题是少量目标数据能否抵抗错误借用，结果不能评价完整 MAP 的功效或临床一类错误。
- [Gneiting 与 Raftery 2007](https://doi.org/10.1198/016214506000001437) 给出严格适当评分的依据。对每次真实/合成兑现 y，以 Brier `(q−y)²` 与自然对数损失评价边际概率，不用某次兑现认证校准。组内依赖参考 [Kerry 与 Bland](https://pmc.ncbi.nlm.nih.gov/articles/PMC1113123/)。不完整二元观察与生存删失边界参考 [NIST](https://www.itl.nist.gov/div898/handbook/apr/section1/apr131.htm)。
- 研究脚本为独立编写，依赖 NumPy/SciPy，仅做本地研究。[SciPy 特殊函数](https://docs.scipy.org/doc/scipy/reference/special.html) 用于反 Beta CDF 和 log-Beta。以整数形状的二项尾多项式复核反 CDF，以 `Beta(9,1)` 与均匀混合的全失败解析权重复核更新。没有把 Stan/RBesT 或其代码引入 ProbSpan，也没有改变现有 oracle。

## 复现、准入和评分

[实验脚本](../research/preview_history.py) 产生记录，不直接生成汇总二项计数。字段含记录键、规范单位键、主体、层、簇、查询、修订版、事件及单位、观察时距及实际随访、时间、工艺、抽样、结果。生成器另保存真值用于审计及评分。来源、目标训练、较晚评价窗的单位键互斥，使用较早记录拟合，评价每层另生成 160 个目标兑现；同一已见目标主体的晚期数据可评价该主体，来源训练组与目标主体一般不同，漂移情形保留跨工艺同主体。区间覆盖按模拟中的已知 q 判定；独立重复的覆盖率蒙特卡洛标准误最大约 2.8 个百分点（n=320）。非常小的差异不作优势判断。

| 场景 | 生成机制与观察条件 | 证据处理 |
|---|---|---|
| shared / shared_zero | 两层全部 p=.20，来源各 8 组×20，目标各层 4 或 0 | 已声明共享；零目标严格估计弃权 |
| heterogeneous | 每层源和目标的组风险独立来自 `Beta(12μ,12(1−μ))`，μ=.15/.45，目标各 4 | 支持层内组参数交换，直接共同参数池化/来源标准化排除。真 q 随目标组变化；覆盖率按该 DGP 的重复实验平均 |
| mix_shift / missing_support | p=.05/.45，目标权 .90/.10，混合场景目标训练 18/2、来源每组 5/35；缺支持场景第二层在两训练集均空 | 只按层转移；第二层有正权重而无观测时不得重分配权重 |
| hidden_conflict / hidden_conflict_zero | 源 .10、目标 .55，仍带当前工艺标签且声明共享，目标各 4 或 0 | 模拟证据声明错误，准入程序不可查到隐藏真值。检验各借用方法的失败程度 |
| declared_conflict / temporal_drift | 源 .10、目标 .55 或 .45，标记旧工艺，漂移场景包含跨时间同主体 | 严格目标路径保留，带旧工艺的借用排除 |
| overlap / duplicate | B 查询复用每组前半或全部记录，观测键/版本不变 | 按规范键去重；同键异标签应拒绝；报告绕过的结果 |
| cluster | 5 条不同单位共用一次 Bernoulli 结果，来源簇内完全相关 | 来源 iid 路径排除；未拟合簇模型，也不删去不同实体的真实观察 |
| outcome_selection | 来源保留所有事件和约 25% 非事件，真实 p=.20 但入选的条件 p=.50 | 用可观察的抽样标记排除；未假设可从结果反推入样概率 |
| incompatible / censoring | 不同事件版本的结果恰有相同生成概率；另一场景一半记录 50 小时停止，100 小时结局缺失 | 错定义即使得分好也排除；绕过时将缺失误填 0，展示向下偏差。此为粗化反例，没有拟合生存模型 |

每个场景在 admitted 和 bypass 下使用同一训练/评价数据及模型随机数。admitted 是本实验的**元数据加声明**准入规则，不能认证真实交换性。bypass 供压力测试，在同一批输入上忽略准入、允许已声明异质的组被池化、保留重复行并把不完整结局误填 0。按同一场景、同一目标比较。表中区间覆盖、区间宽度、绝对误差、偏差、Brier/log loss、阈值错误及错误确定性均只对输出预测的重复计算。弃权率单列；部署策略的期望损失取决于弃权代价。脚本记录三个示例阈值 .15/.30/.45。若真实 q 与阈值 t 异侧、决策错向，定义阈值后悔为 `|q−t|`（等价于一个归一化线性决策示例）。区间完全落在错误一侧属于错误确定性。对每次弃权成本 C，合计损失为『所有重复的阈值后悔均值（弃权计零）+ C×弃权率』。这些阈值及代价不是产品验收值。

### 如何解释这些差异

- **共同机制与稀疏性。** 严格历史只有 8 条记录时，MAE .1046，直接池化 .0166。在来源与目标共享参数的 DGP 中，复杂方法没有必要。零目标时严格估计 320/320 弃权，来源池化 MAE .0177。固定正例只验证本场景的假设。稀疏时能算估计量，仍不满足 v1 历史 EV 的统计门槛。
- **总体改变与缺支持。** mix_shift 目标真值 .09，来源比例 1/8、7/8，故源粗率预期 .40。标准化 MAE .0213、宽度 .1003，目标分层 MAE .0428、宽度 .2115；绕过池化的 MAE .2923，.30 错误确定性 90.62%。标准化实际覆盖 92.19%，不宣称达到 95%。缺支持时各准入方法均 320/320 弃权。若另有充分约束，可研究部分识别的风险界；本实验没有给出缺层概率。
- **误差、覆盖与决策可能冲突。** heterogeneous 中层级对 EB 的 Brier 差仅 .0003，不据此指定优胜者。EB 覆盖 80.94%、层级 92.81%、稳健 94.69%。只用目标分层 MAE .0998 明显更大，但 .30 阈值平均后悔 .0137，好于层级的 .0195。只凭 MAE 会选出不同方案。
- **隐藏冲突。** 隐藏冲突下，严格历史 MAE .1257、稳健 .1898、层级 .3319、池化 .4383。稳健相较池化减少错误确定性（100%→1.25%），仍有 35% 错向；严格历史为 8.75%。零目标时，稳健覆盖 96.88%、宽度 .5431，同时 100% 错向。严格路径完全弃权，其风险为业主指定的弃权代价 C，稳健在该 DGP 和 .30 阈值的平均后悔为 .25。 C 未被产品决定。冲突已标记时，来源路径 320/320 弃权，目标严格路径仍 320/320 可估计。
- **记录与选择。** 同一重复内，纠正 overlap 后池化覆盖 .9594（绕过 .8844），纠正全复制后 .9625（绕过 .8594）。绕过使区间变窄但 MAE 几乎不变，点分数无法可靠揭示双计。簇绕过覆盖 .6781；选择绕过 MAE .2794、错误确定性 .9906；不完整随访补零覆盖 0。错事件版绕过得到 MAE .0176，预测分数不能验证语义。已知缺陷的合法来源路径弃权；若选择机制已知，可另作加权校正研究。

### 超先验与稳健参数敏感性

这些运行用相同种子和场景，生成与推断随机流分开。网格分辨率和 κ 上界联合改变，不能区分其单独影响。改变弱成分并调整上限，观察其对区间和决策的影响：

| 比较 | 基线 | 改变后 |
|---|---|---|
| heterogeneous，EB / 层级覆盖 | .8094 / .9281 | 41×41 网格且 κ≤256 时 .7969 / .9156 |
| 有目标的隐藏冲突，稳健 MAE / 错向 | .1898 / .3500 | 弱权 .5、cap 20 时 .1426 / .1781；弱权 .5、cap 80 时 .1471 / .2125 |
| 零目标的隐藏冲突，稳健 MAE / 错向 | .3691 / 1.0000 | 弱权 .5、cap 20 时 .2494 / .5031 |
| 零目标的共同机制，稳健 MAE / 错向 | .0610 / .0187 | 弱权 .5、cap 20 时 .1506 / 1.0000 |

三次实际敏感性运行去掉 wine/fixture 参数并各用一个新输出名，分别附加：

- `--case heterogeneous --grid 41 --max-k 256`
- `--case hidden_conflict --case hidden_conflict_zero --case shared_zero --weak-weight .5`
- `--case heterogeneous --case hidden_conflict --case hidden_conflict_zero --case shared_zero --grid 41 --max-k 256 --weak-weight .5 --cap 80`

增加弱成分对隐藏冲突有益，在共享机制且无目标记录时会使 .30 决策显著变差。这里只检查有限网格和一组隐变量生成设定。连续漂移、部分簇相关、组大小信息性、测量误差、权重估计及交叉依赖仍待验证；不能推导部署覆盖或通用有限样本保证。

### 公开记录的外部反例

实际读取 [UCI Wine Quality](https://archive.ics.uci.edu/dataset/186/wine%2Bquality) 的 Cortez 等 CC BY 4.0 数据，仅保留聚合分析结果。定义二元结果「质量分数≥7」，红葡萄酒 217/1599（13.57%），白葡萄酒 1060/4898（21.64%）。逐字段完全相同的超额行分别 240 与 937。可用列不能确定同一实物、独立批次、抽样总体、时间次序或可转移性。因此没有擅自去重、随机拆分声称域外验证、拟合借用或报告真实总体的参数覆盖率。原始 ZIP SHA-256 为 `3ed56667f4b828242bd732d7d1dd7f2861e54432239d7fa63877014cbb0304d4`，两个 CSV 内容哈希见结果 JSON。

### 复核与审计记录

第一遍代码与数学复核发现严格聚合 Jeffreys 遇已声明不共享的层应弃权，新增不使用来源的目标分层对照，bypass 的聚合留作错设对照。第二遍记录级复核发现，只将真实补事件置缺失再以 0 填回不能构造偏差反例，故改为一半单位只观察 50 小时、完整结局缺失，最终重跑默认套件。同时从观测键冲突检查中移除模拟真值，时间漂移加入跨工艺同主体。首重复明细 9,924 条，SHA-256 `31cd57299dc7db9f8383dd8ee8537880c1612a0c3d9ffbb7502155b7e256dd96`；默认结果 JSON SHA-256 `598c8abd92375ed24c3ddc254ae40ce2f72ac72832e4897bb30af84a09d958e7`。散列是当次字节证据，跨平台数值重放按容差理解。

同环境用相同配置单独重跑 mix_shift、missing_support、duplicate、hidden_conflict、hidden_conflict_zero、censoring，84 个结果单元与默认 JSON 逐值相同。独立核算从生成记录重新汇总，使用 Python Fraction 计算两种总体混合预测、复制场景的去重前后池化以及隐藏冲突的严格预测。合计五个结果单元各 320 次的 MAE、Brier、.30 阈值后悔均与产物相符（差 < 1e−14）。该复核重用数据生成器，不是对全部模型的独立实现。对于现有 C 实现，用 GNU 16.2.0 UCRT64 的临时 MinGW Makefiles 构建，Release 配置启用 BUILD_TESTING 并禁用 FindPython3，`cmake --build` 后 `ctest --output-on-failure` 通过现有 7 个 C 测试。未运行跨平台 CI 或 Python fixture freshness。

## 对架构、账本及下一单元的影响

- 明确外部选择与可比性判断在计数前完成。调用方保存事件和上下文版本、快照/规范观测键、重叠处理、排除原因、目标权/来源抽样及对照组。源适用度独立于模型/数值状态。异质或未知不用凑 (0,0) 触发 NO_HISTORY；读取真实错误状态。证据没有标签的情况下，来源适用仍需实验之外的论证。
- 结果设计仅随已选实际对象。外部标准化至少暴露目标风险、层风险、权重和不确定性、支持/拒绝原因、结果类型/版本及数值方法。期望回报的几何变换可适用同一结算事件；正 EV 的尾部质量须由对应目标后验计算。v1 的 [历史分析](../src/historical_analysis.c) 用计数重建 Beta，不能用其他模型填充既有结构。保留 [v1 API](API.md)、[行为](BEHAVIOR_SPEC.md)、[数值契约](NUMERICAL_CONTRACT.md) 与 [兼容性](COMPATIBILITY.md) 关于 gate、先验、赔率和 provenance 的语义。
- 对 D38/E47，回放至少需要有效逻辑字段、来源修订、截止/观察期、抽取与去重规则、目标权、模型/超先验/区间算法版本、参数和结果、随机算法与种子、工具版本和容差；无需统一图数据库或固定持久化格式。对 D39/E46，先证明所需区间类型及尾部概率，再谈独立内部数值实现。严禁把 v1 的模型编号复用于其他对象，也无需通用插件框架。
- 对 B15–B17、C23，只保留同任务有足够组与外部留出证据的研究路线。任何将 EB 参数不确定性视为零、对缺失支持重新加权、自动折扣或任意加入伪计数的产品方案不推荐。B19–B21/D40 优先外部来源纪律。E45 的数据库提案不构成统计前置设施。见 [Issues #9](https://github.com/RXY712200/ProbSpan/issues/9)、[#10](https://github.com/RXY712200/ProbSpan/issues/10)、[#8](https://github.com/RXY712200/ProbSpan/issues/8) 和 [永久账本](TECHNICAL_DEBT.zh-CN.md)。
