# 估计对象与接口合同提案

以下签名是设计草图。所有输入由调用方持有，数组只在调用期间借用，输出不得与输入重叠。标量概率用 [0,1]，计数用 uint64_t。函数无时钟、文件、隐式随机数或全局可变状态。INVALID_ARGUMENT、EMPTY、UNSUPPORTED、NUMERICAL_FAILURE 与成功分开。除文档指定的成功且部分可识别结果外，失败时保持输出原值。先验证指针/长度及枚举，再校验数据和模型域，最后计算。资源或精度耗尽有显式状态。

## V2-F001 固定样本二项置信区间

`ps2_binomial_interval(method, events, n, alpha, sidedness, out)` 返回 p 的置信集、方法与名义水平。每一单位同端点、同观察时窗、独立且共享 p。0≤events≤n、1≤n≤10^6、alpha 初始支持 [1e-10,0.5]。n=0 为空。Wilson 使用 z=Φ⁻¹(1−tail) 解 score 二次不等式，仅承诺近似覆盖。Clopper–Pearson 下界为 Beta(k,n−k+1) 的 tail 分位数，上界为 Beta(k+1,n−k) 的 1−tail 分位数。双侧 tail=alpha/2，单侧 tail=alpha。边界 k=0 下界 0，k=n 上界 1。单侧零事件上界用 -expm1(log(alpha)/n)。单侧无约束端为 0 或 1。离散反演数学合同为固定 n 至少名义覆盖，浮点近似按数值预算验收；重复窥视不在合同内。0/10 的单侧 95% 上界约 .258866，十次复制同一次观测违反独立条件。

## V2-F002 显式先验、同质更新与预测

`ps2_beta_update(prior, events, nonevents, out)` 返回声明先验、后验形状与单个未来同类单位的预测均值。`ps2_beta_predict(posterior, future_n, wanted_k, out)` 返回未来批次事件数的指定点质量、均值及方差。限定有限正先验形状 [0.5,10^6]、历史总数 ≤10^6、未来 n≤10^4、k≤n；域外显式拒绝，避免在 v2 首版承诺任意形状。后验 a=a0+k，b=b0+n−k；m=a/(a+b)。未来批次质量为 C(N,k)B(a+k,b+N−k)/B(a,b)。方差 N m(1−m)(a+b+N)/(a+b+1)，与 plug-in Bernoulli 批次不同。采用相邻质量递推及按峰归一，输出另含 log PMF；有限 log PMF 可对应下溢为 0 的 PMF，需标记。N=0 给点质量 1，空历史为明确的 prior-only 输出；只有合格历史才参与更新。Beta(1,1) 加 1 成功 2 失败成为 Beta(2,3)，预测一件为 .4。未知目标机制时所谓“稳健”先验的零目标结果仍完全受先验支配。将域有冲突的源直接加到目标计数为调用方误用。v1 gate 不参与此计算。

## V2-F003 已知权的目标标准化与部分识别

`ps2_standardize_fixed(strata, count, out)`，1≤count≤1024，输入每层目标权、支持标记、同端点同预测时距的目标条件风险点值。调用者断言层互斥完备、权固定、条件风险可用于目标。有限非负权，以补偿求和对编码权的实数和 W 执行 |W−1|≤1e-12 的闭区间判定，再除以 W。1e-12 是输入归一政策，精确边界与数值误差合同见下。完整支持时返回 Σwᵢpᵢ。未知正权层产生锐界 [Σ已知wᵢpᵢ, Σ已知wᵢpᵢ+Σ未知wᵢ]，点值不可读；零权未知层无影响。该界以已知层风险当给定量，未传播风险估计误差；无置信或后验区间。权 (.8,.2)、风险 (.1,.4) 得 .16；第二层未知得 [.08,.28]。删去第二层再归一改变总体。估计权与风险同源时，联合协方差项 2pᵀCov(w,p)w 不能丢。

## V2-F004 竞争风险

`ps2_cumulative_incidence(rows, length, horizon, out)` 接收同起点队列的聚合风险集，初始人数、递增整数时间 tick，每个时点指定原因、其他终末原因和失访人数。调用方提供可观测截止 tick，期限超过该截止时拒绝。长度和总人数上限分别为 10^6 和 2^53。空行表在确有随访及非空风险集时表示零退出。风险集用整数减法维护，风险和使用补偿累计。期限内同 tick 的事件用移除失访前风险集。验证总退出不超风险集，空队列返回 EMPTY；全体失访且期限更远时返回 UNSUPPORTED_HORIZON；若 S 已为零，后续累计风险保持。只提供点估计与支持诊断。S(t)=∏(1−d_all/Y)，F_j(h)=Σ S(t−)d_j/Y。假定独立观察单位、非信息性截尾及共同起点。首个 tick 10 人中 2 个指定原因、3 个竞争事件，无失访，F=.2、S=.5。以后 5 人中再有 1 个指定事件，F=.3。把竞争事件作为截尾的 1−KM 得 .36。拒绝延迟入组、重入风险集、未分类原因及匿名成功/失败计数。每一行的物理单位由调用方记录，函数仅使用顺序及 horizon。

## V2-F005 固定档案的成对预测评价

`ps2_score_paired(rows, length, cutoff, out)` 接收调用方已去重的同一队列及目标键、整数发布/截止/兑现时间、明确真值版本、可用时间、两个可缺席的 [0,1] 预测、可缺失二元标签、明确的非负固定权。冻结档案需满足发布≤发布截止<兑现≤真值可用≤评估 cutoff 才可评分；尚不可用仍计请求。行权为 0 或在 [2⁻⁴⁰,1]，长度≤10^6。零权仍计请求，跳过损失计算，避免 0×∞，不产生无限标记。单行数值 p 的编码端点决定无限分支，概率接近端点不被裁剪。Brier=(p−y)²，log loss=-log(p) 或 -log1p(-p)。错且确定的预测标记无限损失，不裁剪。共享可评分掩码决定成对差的分母。以 A−B 为差。恰一方无限时差为相应带符号无穷，双无限时差未定义。对有限差值不输出显著性或强制排序。回报请求/已标注/双方答复/共同可评分的计数与权和、各自无限项及成对分数。无共同有效权时保留审计并标记无分数。预先确定实体权或机会权，比较时使用同一掩码与归一规则。p=.8、标签1 的损失为 .04 与 -log(.8)。先聚合后换修订真值或过滤掉困难请求会改变 estimand。评价结果不提供校准认证、因果纠偏或可选停止显著性。

数学与反例来源见 [B 推导](../../research/phase-b/derivations-and-counterexamples.zh-CN.md) 和 [B 实验](../../research/phase-b/experiments-and-results.zh-CN.md)。

## 数值合同与资格阻断

以输入 binary64 的精确编码值为参考，整数用原值。环境沿用 v1 的正常 binary64 舍入和渐进下溢要求。u=2⁻⁵³，η=2⁻¹⁰⁷⁴。计数、状态、零权、未知层、失访和无限损失分支必须精确。以下误差针对计算，和置信覆盖、采样误差、适用性分开。超出输入域为 UNSUPPORTED。无法建立合同内结果为 NUMERICAL_FAILURE，保持输出原值。科学上不可识别仍可成功返回已证范围或只返回审计字段。

### F001/F002 资格域

撤销未经论证的 1e-10 端点和 1e-8 log-PMF 通用门槛。D2.2 先冻结 n={1,2,10,100,10000,10⁶}、k={0,1,⌊n/2⌋,n−1,n} 去重网格、alpha={1e-10,1e-6,.01,.05,.5}、单双侧及邻界。以小 n 有理尾和 80/160 位独立反演比较。CP 用较小单尾的区间残差、相对尾误差与 x 邻接宽度分别记录。参考根处于两编码之间时，报告其夹逼，覆盖要求以向外端点验收；不得靠四舍五入到内侧宣称精确覆盖。Wilson 使用高精度正态逆与稳定根做绝对/ULP 对照，不继承 CP 的覆盖结论。另按 B-E001 对小 n 固定真值枚举覆盖。零事件特式核对 expm1 在最小 alpha 和 n 上界的行为。

D2.3 先冻结先验 a,b∈{.5,1,10,10⁶}、历史量 {0,1,10,10⁶} 两端及中点、预测 N={0,1,10,10⁴} 的端点、众数邻域与低尾，进行小 N 有理质量及独立 80/160 位 log-Beta 核对。分别报告 log 误差（能转化为非零 PMF 的相对误差）、实数质量归一误差、均值和方差绝对/相对误差；对真零、下溢舍入零及有损非零编码分别标记。两种精度须在候选误差额度的十分之一内一致，仍需有理点或可验证区间隔离共同系统误差。资格记录须提交逐量预算及推导、每平台极值、尾部失效域、迭代/工作量上界。须用未参与定预算的中间/邻界点复验。未独立批准预算、覆盖域与最坏失败率前阻断单元接受，缩域须重新评审且重跑资格域。

### F003 归一与锐界

数学参考为编码值精确有理数除法。用可证明误差界的累加包围 W；快速判断只在区间完全位于政策界内或外时成立。交叠时用精确 dyadic 累加及精确十进制政策界比较，或返回数值失败（不得把不确定当无效权）。正常输出须在参考值相邻的两个包围编码内，恰可编码时相等；部分识别下界向下、上界向上，不能收窄真集合。此为表示尺度预算，零附近绝对分辨率至少 η，禁止声称固定相对误差。可采用有界 dyadic 分箱整数累加、定向整数除法；1024 项限定存储及位长，权和风险乘积的指数下限为 −2148。风险正却因下溢舍入为零的点值标记表示损失。全支持已知且点退化时保持点状态；正未知权的判断使用原权（不能先归一舍入到零）。独立 Fraction 或精确区间验证，包括权和政策邻界、次正规输入、最大层数及累加重排。

### F004 产品递推误差

风险人数和每 tick 三类退出严格整数验收；按 horizon 含同 tick 事件，截尾后已无支持且剩余生存正时拒绝外推。F 和 S 用独立 Fraction 小样例和至少 80/160 位高精度/区间重算长样例。候选以每一步正确舍入除法、乘法及误差有界累加为前提，参考预算 E_abs=γ_(6m+8)+8mη（γ_k=ku/(1−ku)，m 为纳入行数），针对 0≤F,S≤1 的非负产品和，不作为相对尾误差保证。实际计算建议直接用整数在险减法构造生存因子，避免 1−d/Y 的消去。资格阶段需给出实现对应的运算路径证明或更紧可计算的误差界，验证上界与被测状态分离；若不能证明，阻断 D3.2 接受。报告 E_abs 及稀尾相对误差，区分结构性 S=0 与正 S 下溢；支持状态依据整数和事件路径，不能读舍入后 S 判定。若 F 或 S 正值在预算内无法与零区分，可附精度受限标记与保守包络，不输出相对保证；越界、包络无法建立或超资源时失败。

### F005 分母、尾损失与差值

参考用 Fraction 生成掩码权和、Brier 和差，80/160 位独立 log/log1p 生成有限 log loss。报告两个有限均值的绝对与相对误差，差值按逐行带符号差并独立补偿累计，消去条件下仅给绝对误差和含参考值的包络。预设每分数聚合预算 E≤(Σw·e_leaf + E_sum)/W + E_div，e_leaf 为已证叶运算绝对误差（含 libm 和乘法分项按量纲记账），E_sum 为对分子求和的界，E_div 包含分母误差与末次舍入，分母区间须严格正。资格报告须绑定具体 libm、误差实测与保守界，按 p={0,η,最小正规数,.5,nextafter(1,0),1}、标签两类、最大行数、极端权、差抵消重放。生产契约不能把实测最大值直接当作数学上界。未能给有限域和可审查预算时阻断 D3.3 接受。正有限 log loss 上界约 744.45；Brier 或归一份额可下溢，零编码不等于完美预测。若差值包络含零，方向为不确定，禁止用一个全局 epsilon 判胜。无共同有效权、单边/双边无穷均使用独立精确状态。
