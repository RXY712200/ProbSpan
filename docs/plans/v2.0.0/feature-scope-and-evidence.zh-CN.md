# 功能范围与证据

推荐 F001–F005 为新 C11 能力，F010 为兼容基础，F011 保留现有可选参考。旧 1.1.0 只有冻结 Jeffreys 点/区间与 gate、主观区间、赔率与 EV、provenance 和组合。新范围提供独立频率学派置信集、先验声明及预测计数分布、总体目标风险的可识别界、原因风险集分析和可审计的预测评分。这些产物不能彼此代替。

| 家族 | 工程与科学取舍 |
|---|---|
| A | Wilson 与严格二项尾反演各有用途。覆盖/宽度代价须并列报告。尾分位是主要实现风险，优先独立参考。先验与批次预测独立类型，零数据可 prior-only。 |
| B | 完全汇聚仅在同参数、独立与准入成立时有效。固定权借用的折扣并非随机不确定度，零目标时混合权不会学习冲突。EB 插件遗漏超参数不确定性，完全层级需要留整组外验证及可靠后端。B-E007 的同球员留出不能认证新组，故 F006 先留给独立验证，F002 提供明确的单群模型。 |
| C | 固定权支持标记、数值可界是低依赖的纯计算。随机权与风险联合估计、簇推断和跨总体稳定性由调用方补证。加权替代目标风险而非朴素合池，旧两层 Python 参考继续作为可选实现。 |
| D | 小型 AJ 点估计可用独立有理参考；付出风险集专用输入与截尾合同。可选调用方可先调用生存工具。Poisson 同质率需暴露且条件过程假设，未来计数、风险和危险率不可强转。 |
| E | 纯 evaluator 能以 O(n) 分数和有界输出覆盖成对预测用途，保存快照/数据库是调用方任务。选择性标签不能自动纠正。分组多轮及校准学习暂由调用方处理。 |
| F | 特征后训练需时点、样本外划分及校准，连续与时间模型需不同观测单位。边缘 .4/.4 的联合可为 0 至 .4，通用融合拒绝。保留 v1 主观结果和 EV，专家引导在域外。 |
| G | 单独报告表示误差与科学适用性。门槛附近相反的十进制输入可舍入同编码。B-E006 的 10/15 严格与 15/15 容差验证不能支持更强承诺。 |

[特性登记](feature-register.tsv)给每个操作的输入、单元、门槛及多对多 A/B/C 引用。B-E001/002 是限定 DGP 枚举，003/004 为有条件模拟，005 为构造与动态规划，006 是独立数值核对，007 为棒球档案留出。合成验证、数值复核和领域真实性分开。挂起项据其数据要求归调用侧或补证，新增功能范围仍需评审。
