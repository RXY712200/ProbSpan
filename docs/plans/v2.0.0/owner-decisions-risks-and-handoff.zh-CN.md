工程师可在已接受预算内选择补偿求和、递推细节和测试工具。公共支持域、功能删减、许可变化、改变旧 ABI、运行依赖和发布由独立评审与所有者处理。任何外部验证声明需具体目标总体、抽样/失访机制、原始端点定义、前置预测和许可。参见 [C 原登记](../../research/phase-c/decision-register.tsv)。

反向攻击检查：以零目标标签试图区分借用冲突必失败；已编码 odds 对应多个实数时不能恢复文本外的信息；风险集记录无法由匿名二项计数恢复；权为随机或和风险共估时固定权输出只作敏感性参照；高分母预测实体可能支配总体分数；后验置信混称、时钟倒灌、Python 泄露到根安装和共享数值回归均视为实质失败。识别限制、运行数值失败和平台待验证分别记录。当前工程计划未改变永久条目，也未批准任何发行。

交接从已接受的 D1 PR 树、此登记与精确 baseline 恢复。独立审查优先攻击 CP 尾部、风险集支持为空、双包 CMake 兼容和评价时间合同。完成评审后由所有者确认范围、包边界及下一 D2.1 任务权限。仅在获准后实施。
