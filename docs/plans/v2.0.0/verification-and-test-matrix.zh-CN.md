## 数值资格记录

F003 用精确 Fraction 比较归一权、权政策邻界和外向锐界，包括次正规、正未知权和最大层数，突破相邻编码或内缩即失败。F004 用有理小风险集与 80/160 位长序列重算 CIF/S，区分真零与下溢，覆盖同 tick 退出和支持耗尽；资格报告须证明累计误差界与实现匹配。F005 用 Fraction 比较权和、掩码与 Brier，用独立 80/160 位重算 log，覆盖消去、亚正规、零权与双无限；未证明分母正性或未冻结分区预算即拒绝接受。D2.2、D2.3 同样须完成盲测邻界、预算批准和域记录。公式、网格、精度预算与阻断条件见[模型合同](estimands-models-and-contracts.zh-CN.md)。记录每平台最大误差、升精度分歧、有效输入失败比例及可用资源上界。未通过时停在原单元并复现，不把失败当作普遍逃生路径。
