# 固定执行路线

五阶段及固定单元数为 **D1 6、D2 3、D3 3、D4 2、D5 2**，共 16。D1 是本次规划。D2–D5 是提案，经独立接受并获得后续明确授权再执行。每行是一项可评审单元，数值与失败合同由[模型合同](estimands-models-and-contracts.zh-CN.md)和[验证矩阵](verification-and-test-matrix.zh-CN.md)共同限定。

| 单元 | 前置 | 范围 | 产物 | 通过条件 |
|---|---|---|---|---|
| D1.1 | - | 证据与账本交叉定位 | 特性登记 | 48+8+4 映射及引用可重跑 |
| D1.2 | D1.1 | 选择分析增量和排除项 | 范围 | A–G 均有取舍 |

D2.2–3 在包装基线后可独立研究和验证。D3 三模块之间无运行依赖，作为实施阶段在 D2 接受后启动。D4 汇合全部拟定功能，常规问题留在原单元复验。任一合同、精度、依赖或兼容门槛失败则停在原单元，记录复现与剩余影响。范围变化需要重新取得批准并记录替代清单。完成一个单元只证明该产物送审，实施、合并、发布、版本批准均按对应动作授权。规划的预览或候选时点见[发布策略](preview-rc-stable-strategy.zh-CN.md)。每项实施更新相应指南、测试、范围和必要的债务证据，永久编号保留。机器可读依赖见[登记表](work-unit-register.tsv)。
