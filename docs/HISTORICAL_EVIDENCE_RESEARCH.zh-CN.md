## 1. 最小建议及当前事实

先在调用方建立目标、证据来源、适用性论证和快照契约。只在确有证据支持同一 Bernoulli 参数且可视为独立观测时调用现成 v1 计数估计。对未知适用性保留原因并弃权；必要时另行展示来源总体的描述性结果，不能标为目标概率。阶段 II 可比较具体数据场景中的严格历史、已论证队列池化、分层标准化，以及有条件的独立参考模型。数据库、统一路由、通用持久化、插件机制没有构成前置要求。

## 2. A08 / B13：先定义目标与证据类型

目标记录最少表达 estimand、事件定义 ID/版本、判定阈值及含等规则、单位/空间支持、观察单位与分母、结算及缺失/删失/未成熟规则、目标总体与抽样框、起点/时距/有效窗口/截止时刻、已知信息集、上下文与干预/工艺版本。定义 ID 相同还需核语义版本和使用范围。事件和其补集必须在同一合格、已兑现单位上互斥且穷尽；未完成不自动进入补集。记录采样窗口与每条结局的观察时距，二者不能混用。

| 证据对象 | 最小单位及记录 | 可回答的问题 | 禁止的替代 |
|---|---|---|---|
| 真实历史观察 | 一次合格暴露/单位，主体与群组、实体事件键、条件、结局及成熟时间，采样机制 | 同一过程概率，或在已论证转移下推断目标概率 | 缺失/删失算失败；回填未来信息；把重复发布算新试验 |
| 专家判断 | 人/过程、判断时刻、已见证据、目标、诱导方法和概率或分位 | 结构化信念、必要时在明确先验构造下作敏感性输入 | 把三名看过同一报告的专家意见当三次真实试验 |
| 模拟/集合 | 模型、版本、输入/情景、权或抽样机制、运行键、种子/成员共用来源 | 给定模型下的阈值概率或情景结果；另核模型误差 | 把成员数或重复种子扩增当真实世界样本量 |
| 预测—结果配对 | 预测键、发布时刻、预测分布、信息截止、地点/时距、验证键及结果修订 | 评分、校准及模型比较；同一次结局可配对多个预测但必须保留依赖 | 按模型版本重复计入结局样本；把模型准确率当新事件概率 |

带特征的真实观测属于第一类，但保留特征和时间才能训练条件预测；聚合为 e,c 一般不可逆。计数率要有暴露量，首次故障要有风险集/删失，连续结果要有单位与分布，联合概率要有成对观测或依赖假设。A03/A05 的一次性事件在缺少映射、数据和可信判断时可能无法识别；拒绝输出虚构的 0.5 或伪计数。

例：ECMWF 的单地点、固定时段降雨超阈值，与大区域“任一地点”或多日“任一天”是不同事件。物理集合的超阈值比例依赖网格/点、阈值、时距和模式版本。更密的集合可降低某些模拟误差，不能给实测降雨增加记录。再预报用于校准时需与同期雨量计、窗口及空间代表性对齐，重复时距预测可能共享兑现；同一暴雨过程要按组切训练/验证。[ECMWF 概率指南](https://confluence.ecmwf.int/spaces/FUG/pages/673550806/Section%2B7.1%2BConsideration%2Bof%2Bprobability) · [点雨量及验证](https://confluence.ecmwf.int/spaces/FUG/pages/673551197/Section%2B8.1.7%2BPoint%2Brainfall)

例：可靠性资格试验中的“某硬件版本在完整 100 小时内首次故障”与工单数/总机时、或保修投诉比例不同。50 小时退出且无故障的机器结果未知。将其算入未故障既改分母也改风险集；更换硬件后同一序列号不保证机制相同。若完整观测且定义相同，可从原始时间重新生成给定时距二元标签；只持 50 小时聚合计数无法变换成 100 小时计数。[NIST 删失说明](https://www.itl.nist.gov/div898/handbook/apr/section1/apr131.htm)

## 3. B14 / B21 / D37：适用性、识别与就绪分别判断

先核对来源和目标定义。允许可复核的逐记录重标，例如可重取的原始降雨量从 ≥ 改成 >，并保留旧定义及转换损失。不兼容聚合不得靠先验“修正”。随后分别问观测是否为目标总体抽样、是否存在选择/观测概率差异，条件机制是否可比较，支持集是否覆盖，重复及依赖是否得到模型处理。声明、已检查证据和假设分别保存；通过有限回查不证明不可观测交换性或未来稳定。

候选外部判定（说明性分类，无 API）：适用可直用（已支持共同二元参数与独立性条件）；条件适用（仅指定层、映射、设计或目标权重成立时，交适合的分析路径）；不适用（已知错误定义/不可修复支持缺口等）；未知（信息不足）。判定记录针对目标、来源、模型与时间窗口，可以逐层、逐源有不同结果。缺失原因、重评触发、可用范围与拒绝对象必须明确。条件适用不可隐式走 v1；与统计状态正交。适用且样本少可显示后验为未就绪；错误定义的百万样本即使 v1 数值可算也不能用于目标。按分层分析时未覆盖层可报告部分覆盖；不得默认把无观测层的总体权重重新分摊后仍称原总体。

以来源 S、目标 T 说明描述性风险的标准化：若定义一致，对必要 X 有 P_T(Y=1｜X)=P_S(Y=1｜X)，且目标权重非零之处有足够来源支持，可用 Σ_x P_S(Y=1｜X=x)P_T(X=x)。须论证 X 决策时可用并对缺失、选择及测量机制有适当处理。目标权重必须可取得；若来源入样依赖结局且无可信设计/观测机制，这个等式无法凭重加权成立。逆选择权/密度比是特定设计下的估计方法，极端权重会扩大误差，截尾改变偏差或目标；权重与风险估计的不确定性都要传播。来源/目标均值相近不说明条件一致；重叠存在不证明条件稳定；概念漂移不能只看 X 检出。缺某关键层时可改目标并明确范围，作外推敏感性分析，或直接弃权。不要从检验未拒绝推出可传递。

Dahabreh 等在多项随机试验中讨论固定随访、条件效应可交换性和 positivity，示范 HALT-C 多中心数据，用目标协变量样本进行标准化/加权并讨论敏感性。文章的因果量与这里的描述性风险不同；其识别思路可借鉴，假设不能直接移用。Bareinboim 与 Pearl 用选择图表达环境机制变化，识别依赖假设和可用数据结构。两者均不从数值相似度自动推出匹配。[Dahabreh et al.](https://pmc.ncbi.nlm.nih.gov/articles/PMC9066547/) · [Bareinboim & Pearl](https://pubmed.ncbi.nlm.nih.gov/27382148/)

可核算反例（合成，非性能证据）：来源 90% 低风险（0.01）、10% 高风险（0.20），粗风险 0.029；目标权重交换后为 0.181，条件机制未变。若目标高风险层真实风险改为 0.40，标准化仍给 0.181，而真实为 0.361。没有目标结局时两种机制可拥有同样 X 分布，无法从 X 推断是哪一个。真实临床历史对照的检测标准、入组与护理时代变更造成同类问题。Issue [#10](https://github.com/RXY712200/ProbSpan/issues/10) 的匹配问题必须先于 [#9](https://github.com/RXY712200/ProbSpan/issues/9) 的借用强度。

## 4. B19 / B20 / D38：重复、依赖与可复现性

重复指同一证据出现多次；相关指不同证据共享主体、批次、事件、算法、风险或连续时间。不同文件/hash/查询 ID 都不能证明不同观测；相同字段也可能是真实不同观测。调用方在聚合前按来源命名空间和被验证的规范观察键等价规则去重，保存修订/撤回及冲突处理。两窗口时间相交未必重叠样本，时间不交也可能共享人/设备造成依赖。若只有边际聚合，无法据其恢复交集及标签或检测重复，要求稳定成员轨迹、可信不交证明或重新抽取。已有同一对象重复定义、互斥窗口、不同标签等冲突须停止相应合并。隐私敏感场景可保存受控对象引用和审计摘要，避免公开成员标识。

统计上，同一批次内 m 个等相关二元结果，独立等大批次、相同方差下，直接展开样本均值方差得设计效应 1+(m−1)ρ。100 组每组 10、ρ=0.2 时为 2.8；1000/2.8≈357.14 仅为该方差对照下的有效量，不能四舍五入成 v1 独立计数。若 10 次上报来自同一观测，先去重，不做断言式 ICC 校正。若 10 台机器确实不同但共用一次停电，保留失败而对依赖建模。组内依赖、组间异质性、随时间漂移需要不同因子；若只剩 e,c 它们都不可恢复。比较按群组抽样/验证、簇自助法（独立簇足够时）、分层组模型和时间切分的适用性。簇少、极端不等大小或主观设定 ICC 时报告不稳定。估计“随机机器”与“随机批次平均”的权也可能不同。[Kerry & Bland 的设计效应与实测例](https://pmc.ncbi.nlm.nih.gov/articles/PMC1113123/)

合成成员核验例：查询 A={u1:1,u2:0,u3:1}，B={u2:0,u3:1,u4:0}。直接相加是 (3,3)，并集是 (2,2)；另一个不相交的 B 可以有相同边际 (1,2) 却给出 (3,3)。在同一先验下两种后验均值均为 0.5，但错误相加使后验方差由 1/24 降至 1/32。若 B 对 u3 报 0，须用版本/权威规则解决或隔离，不能选一个结局凑计数。

按需保存 C 内核之外的逻辑快照。最小含：目标与定义版本、证据种类、数据快照及内容摘要/访问引用、上游来源与共同根、采样/缺失/截断协议、观察键规则/群组/重叠审计、归一化定义/映射版本、查询参数和代码/环境标识、截止时刻及修订时间、纳入排除计数和原因、适用性论证/假设/未证实条件、使用的源/目标权重、算法及模型/gate/result/数值契约版本、原始输入/返回值/状态及复现容差。存在 Monte Carlo 时还要记录生成程序、RNG、种子、链/收敛、误差与运行环境；种子自身不保证跨实现位相同。哈希证明内容身份而非语义或独立性；若源不可重取或原明细删除，应明确仅能回放既存结果或重新运行计数摘要，不能复验采样。追加更正指向原快照，原分析与新分析保持可区分。W3C 实体/活动/代理及派生关系可作为语义参照。这里无需图数据库、RDF 或强制持久化格式。[W3C PROV-DM](https://www.w3.org/TR/prov-dm/)

## 5. 数学候选、适用条件和拒绝理由

| 路径 | 成立前提与证据 | 失败与取舍 |
|---|---|---|
| 严格目标历史（必比较） | 可辨识目标、明确抽样、共同稳定 p、独立合格结果；使用 v1 无需重写 gate | 稀疏时弃权或标估计未就绪；不能用 gate 弥补错抽样 |
| 已论证队列全池化 | 上述条件跨主体成立，且无重叠；组织/ID 不自动授予可交换性 | 真正异质时伪精确；独立同 p 才可用 e,c 求和。只按列名/同主体/相似率自动 pooling 拒绝 |
| 分层展示、目标标准化 | 层定义和权重准确，有支持且条件机制共享，纳入权重估计及层风险误差 | 单列 EB 或把加权比例塞入 v1 都会改变模型；分层展示有价值而并不总需总体合并 |
| B15 经验 Bayes / B16 分层 | 例：e_j｜p_j∼Binomial(n_j,p_j)，p_j｜a,b∼Beta(a,b)；需合理组定义、组间交换性和组内模型。EB 用历史拟合 a,b 后插件；分层对超参数不确定性积分 | 少数组、目标机制突变、组大小带信息或训练/验证共享主体会使收缩失效。先验敏感性、组外预测及超参数不确定性必查；混合 Beta 的分位数不能平均组分分位数 |
| B17 稳健借用 / C23 新主体先验更新 | 仅对正当来源。用 MAP 混合和弱信息成分组成先验，对目标独立数据更新；Beta 组分 (a_j,b_j) 增加 (e,c)，组分权重按 w_j·B(a_j+e,b_j+c)/B(a_j,b_j) 归一化。未观测新主体是总体预测，不能假装已有其后验数据 | 极少目标样本难检测冲突；超参数、成分权重、冲突样本量和先验宽度影响错误借用、覆盖及决策。异质性模型不修事件错配、重复或选择。若同一目标数据参与先验训练需联合建模或隔离，不重复更新 |
| 加权/时间衰减、按漂移切段 | 有可解释的漂移或采样模型且能回测；时间切段可先作为外部选择 | 任意衰减、naive ESS、固定折扣或“万用相似度”不能提供校准后验。机制变动无新数据时只能声明假设、给敏感性或弃权 |

Stan/rstanarm 的棒球击打案例实施不池化、全池化与部分池化，用后续击打检验预测。其前 45 次正式打数与赛季余下打数分开，后段同球员兑现用于检验已见主体预测；一名球员剩余 367 次打数包含 127 次安打，后段频率同时受参数和未来二项波动影响。文档的复制数据检查显示模拟比例比原早期数据更分散，并指出入选限制。新主体泛化须另做留主体验证。Schmidli 等用四项历史对照研究示范 MAP 与稳健混合，模拟检查操作特性。RBesT 的 gMAP/robustify 文档给出拟合、混合及 Beta 弱信息先验实现；示例的 0.2 弱成分权重与 Beta(1,1) 是具体设计选择，不能视为 ProbSpan 默认值或普适冲突保护；其具体默认值和 MCMC 不移入 C。后续 Pocock/混合先验比较把稳健性联系到漂移方差或弱成分选择，不能归结为一个通用权重；本轮只核其可见摘要/摘录。评分方面，Gneiting 与 Raftery 的严格适当评分理论以同一个预测对象及兑现过程为前提。Brier (p−y)² 与对数损失可评价系列预测，不能从一次兑现识别校准。按滚动起点、留批/留主体和任务/预测时距分层；不能让试验重用预测校准集。[Stan 案例](https://mc-stan.org/rstanarm/articles/pooling.html) · [Schmidli et al.](https://doi.org/10.1111/biom.12242) · [RBesT 二元案例](https://opensource.nibr.com/RBesT/articles/introduction.html) · [后续方法比较](https://academic.oup.com/biostatistics/article/24/2/443/6431722) · [Gneiting & Raftery](https://sites.stat.washington.edu/raftery/Research/PDF/Gneiting2007jasa.pdf)

为明确 B17 的失效边界，用合成混合先验 0.8·Beta(9,1)+0.2·Beta(1,1)。若目标先后观测 0、1、5 个失败且没有成功，弱成分权重依次为 1/5、5/9、1001/1013。这里用预测似然而非任意阈值调权；当目标零观测时根本无法发现冲突。该算例验证权重公式，不证明校准或推荐该先验。

## 6. 架构选择与最小接口边界

建议的数据流是 外部定义/快照 → 类型、成熟性与成员审核 → 目标适用性及依赖论证 → 明确选择分析路径 → 模型特定结果 → 同目标决策 → 外部记录。首先用纸面契约和可复核小数据测例验证。调用方拥有域字典、数据加载、缺失/版本、抽样与身份管理，研究/参考实现承担学习与诊断，内核只承担已证明有价值的纯数学及有限事实校验。欠缺上下文返回应用层不适用/未知，保留 v1 原状态；不可覆写 VALID 或偷偷把错历史伪装成 (0,0)。若确实没有历史，保持 NO_HISTORY 的真实含义。相同来源、目标、证据角色与模型前提一致时，才解释模型关系；不可比较的结果能并列但不可直接报冲突。

| 外部审查情形 | 估计 / 决策处理 | 记录的失败原因 |
|---|---|---|
| 已支持共同目标、合格且有独立观测，但 v1 不就绪 | 可展示 v1 历史区间，保持历史 EV 不可用 | 区分估计存在与 gate 未达 |
| 错误定义或未知依赖且不能重取 | 不生成目标历史结果；主观路径可独立进行 | 明确不适用或未知，不伪造 NO_HISTORY |
| 已验证映射但目标层权不同 | 可展示分层；有目标权且满足假设时可做外部标准化 | 明确目标及不可迁移层，结果附专属不确定性语义 |
| 适用且独立，但求解失败或赔率不合法 | 保留实际 API 错误，不解释为外部数据不适用 | 数值与决策输入错误各别，尊重 v1 短路 |

可选便利（以后按实际重用证明）：域外只读规范化脚本、样本核验报告、稳定形状的清单交换。实现数据源目录、自动匹配、追踪 DAG、存储引擎、通用 C 路由会在目标和数据契约确定前锁错抽象。把全部语义送进 C 会引入动态身份/域政策及 ABI 负担；仅传 e,c 到所有未来模型不可恢复模型关键输入；统一 mean/lower/upper 会混淆参数可信区间、预测区间、评分区间和主观范围。稳健新模型若有理由进入内核，应采用并行、独立版本的结果与评价能力，只有在区间同为所需目标概率且结算语义等价时复用纯 EV 几何。历史尾概率留在各后验能力里。无需移动 Beta/odds 模块或将 provenance struct 改名扩字段。若未来引入 mixture CDF/数值求解，先定义精度、退化情形、尾概率、不可用和不确定性传播，再比较是否重用私有工具，避免借 R01 扩张 gMAP/MCMC 为核心依赖。

## 8. Phase II 研究边界与可证伪计划

建议选择一个有真实、可访问的版本化二元观测任务（例如同一固定时距和工艺的多设备资格数据），必要时先用记录级合成基线检验反例，并把真实数据验证保留为未完成。正例可用固定端点的跨球员部分汇聚数据作为方法参考，只检验指定队列是否可借用；该参考无法证明具体机器可匹配。预先指定同目标、数据角色、包含/排除、完整时距、独立簇、目标权、候选可用状态、损失阈值与绝对回退标准。第一轮比较严格不借用、经论证全池化及分层目标标准化。仅当样本支持跨组关系、独立回测有增益或尚有明确可调查假设，才加入 EB、分层及稳健借用作为独立外部参考。

设计测试矩阵：共同机制不同主体为正例；同主体改工艺、定义 > / ≥、重叠查询、重复副本、相关簇、选择/未覆盖层、总体权改变、条件机制突变、极少目标样本为负例。合成场景掌握真实 p，按重复数据组报告偏差、区间覆盖/宽度、误纳和弃权率、阈值决策错误/损失，模拟误差及种子单独记录。真实留出以时间滚动并隔离主体/簇，报告 Brier 与 log loss、分层校准与目标覆盖率；不能从不可观测的真实 p 直接断言参数区间覆盖。比较同一可评分样本，并分别报告弃权损失与范围，防止只在易例取胜；预定对错借用的最大可接受代价，跨合理先验/ICC/权重/漂移设定仍达标才推荐继续。机制不可证、目标权未知、可比组太少或错误借用决策后果过大时停在严格历史/弃权，并记录最小补证据。待所有者决定真实目标、数据访问、代价/验收界值与是否授权后续数学模型研究；本结果没有选择待实现模型或版本。

## 9. 证据边界与自审

范围内按可核对的门槛审查：v1 公式/判定及测试定位；目标+证据角色；可比性和拒绝/未知；依赖/重叠；适用性正交；可复现字段；独立参考与反例；全部 52 ID；架构方案及 Phase II 停止条件。第一遍从源码和研究证据复核，明确 VALID 属于现行 gate、历史 EV 尾概率不可通用，以及合成反例不是外推证明。第二遍按反例从调用方重走路径：加入缺目标权或支持时不得重分配而仍称原目标、目标数据复用导致双计、含等与删失的可逆条件及回测中的簇隔离。2026-11-18 在 Windows GNU 16.2.0 UCRT64 的临时 C-only Release 构建中，CMake MinGW Makefiles 配置带 BUILD_TESTING=ON、CMAKE_DISABLE_FIND_PACKAGE_Python3=ON，构建后 ctest --output-on-failure 通过全部 7 个 C 测试。Python 标准库 Fraction/comb 独立核对 0.029/0.181/0.361、成员并集计数、Beta 方差、设计效应与混合先验冲突算例。未重生成 fixture，未运行 Python oracle freshness。未验证真实用户数据、候选模型表现、全平台精度或独立接受。本文参考实现只检查公开研究/文档，未导入代码或新增依赖。既有债项的状态与完成证据见 [永久账本](TECHNICAL_DEBT.zh-CN.md)。
