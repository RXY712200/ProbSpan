## 三类历史不能混用

1. **已兑现事件历史**：明确同一事件定义、观察单位、时距和可比总体的成功/失败结果，才可能进入当前 Bernoulli 计数模型。
2. **特征—结果关系历史**：带条件变量的训练样本，支持条件预测模型；简单合并会丢掉条件关系，并可能产生 Simpson 反转。
3. **预测—结果表现历史**：预测前记录的概率、任务、时间/信息集及最终结果，可研究预测过程的校准与评分。不同未来事件也可贡献表现历史，但须任务组可比、避免泄漏并检验校准迁移，不能将所有结果总和当作新目标事件的成功率。

同一主体既非可比性的充分条件，也非必要条件。**Issue #10 先判断能否正当匹配/迁移；Issue #9 再判断借多少；Issue #8 数据库适配继续延期。** 先验折扣不能使无关数据变成合法证据。

**Phase I 研究补充（2026-11-18）**：见[历史证据基础与架构研究](HISTORICAL_EVIDENCE_RESEARCH.zh-CN.md)。全文对 A08、B13、B14、B19–B21、D37、D38 给出独立的证据类型、适用性/依赖闸口及外部快照建议，逐项列出全部 52 个 ID 的前提与返工风险。候选结果形状和 Phase II 验证设计尚待审查；没有改变账本状态、优先级、版本或修复历史。

**Preview 第二研究单元补充**：见[概率模型比较与数学验证](PREVIEW_PROBABILITY_MODELS.zh-CN.md)。B13/B14/D37 的准入边界先于借用强度。B18/B21 的总体权变化对照支持有条件的外部分层。B19/B20/D40 的簇、重叠和漂移对照显示点分数可掩盖错误确定性。B15–B17/C23 的 EB、层级与稳健借用仍属外部研究。D38/D39/E46/E47 的证据版本和区间语义须随已证明的分析需求设计，E45 不构成前置要求。既有条目及状态历史保留。

## A01 — 充分且可比的二元事件历史

1. **稳定标识**：A01，永久保留。
2. **问题名称**：充分且可比的二元事件历史。
3. **第三方场景**：工厂已确认同流程且独立的 800 次合格/200 次不合格，要估计下一同类批次概率。
4. **发生原因**：事件定义、观察单位与可比性必须先成立，计数才能对应一个 Bernoulli 参数。
5. **当前 v1.0.0 行为**：history_estimate 接收非负计数，给 Jeffreys 后验与 gate；不审核工厂的抽样论证。
6. **现有支持程度**：已有计数估计路径解决此限定输入问题，不意味着库自动找到合格历史。
7. **候选算法/处置**：维持 Beta(e+.5,c+.5)；新数据语义审查留在调用层。
8. **可能接口/模块（提案）**：无需新核心 API；可选外部计数审核适配器尚未实现。
9. **数学假设与风险**：条件交换性与目标总体稳定是外部假设，更多样本不能消除系统偏差。
10. **源码与证据**：[historical.c](../src/historical.c)、[API](API.md)。外部参考仅作研究，不是依赖或实现证据。
11. **测试/后续验证**：oracle_parity/check_history 与 large_numerics 检查后验与 gate，真实工厂适用性须域外验证。
12. **依赖关系**：B13、D37 是输入合法性的先决条件。
13. **状态及理由**：RESOLVED；限定场景已有源码与测试支持，剩余边界见风险和下一决定。
14. **建议优先级（未批准）**：P3（保持回归与解释）；不构成实现或排期授权。
15. **目标版本**：v1.0.0 已包含上述限定能力；额外扩展 TBD，未批准。
16. **完成条件**：限定的二元计数估计、错误保持和可用性已有实现与回归，持续保持兼容。
17. **解决证据/剩余限制**：基线 `fdfaddfb58486004ee1cc02c0f4a5c640cd17c7c` 中上述源码与测试已存在，首次正式稳定版本 v1.0.0；具体输入语义与域外验证限制仍保留，非本次新增功能。

## 研究基础与适用边界

以下均是 2026-11-16 查阅的第一方项目/官方材料，**不是 ProbSpan 的依赖、已实现功能或普适历史匹配器**。不导入代码；实施前须重新核对维护状态、许可、模型假设与目标验证。选模型不能代替 B14 的准入。

| 参考 | 可借鉴的具体方法 | 不能由其推出的结论 | 对应条目 |
| --- | --- | --- | --- |
| [Stan binary trials](https://mc-stan.org/learn-stan/case-studies/pool-binary-trials.html) | 比较完全/不/部分汇聚及 posterior predictive 检查 | 组间同名或同主体即交换，或 MCMC 自动使历史适用 | B10、B16 |
| [PyMC partial pooling](https://www.pymc.io/projects/examples/en/latest/case_studies/hierarchical_partial_pooling.html) | 群体分布与单组后验联合建模 | 示例通过代表项目已具分层模型 | B16、C23 |
| [ebbr](https://github.com/dgrtwo/ebbr) | beta-binomial 超参数估计、稀疏比例收缩 | plug-in 超参数区间等同充分传播全部超参数不确定性 | B15 |
| [RBesT](https://opensource.nibr.com/RBesT/) | MAP/robust prior、历史冲突与 operating characteristics | 混合先验可为无关历史建立合法关系 | B17、C23 |
| [SKADA](https://github.com/scikit-adaptation/skada) | 领域适配、权重/表示方法及目标评价 | 任何 covariate/concept shift 都可修复，无 overlap 仍可保证 | B11、B21 |
| [River ADWIN](https://riverml.xyz/latest/api/drift/ADWIN/) | 自适应窗口的流式变化检测 | 检测证明因果机制、立即获得正确新模型，或从未误报 | D40、C34 |
| [scikit-learn calibration](https://scikit-learn.org/stable/modules/calibration.html) | sigmoid/isotonic 与独立校准数据；可靠性图和 proper scores | 排序好就是校准好，或总 Brier 单独测尽校准 | C26、D35、D36 |
| [MAPIE](https://mapie.readthedocs.io/en/stable/content/getting-started/quick-start/) | conformal 预测区间/集合及其覆盖前提 | 区间就是 Bayesian posterior，或无条件具有逐子群/任意漂移保证 | C27、C31、D39 |
| [SHELF](https://shelf.sites.sheffield.ac.uk/) | 缺少硬数据时系统 elicitation 专家信念 | 专家共识成为频率证据或已验证真概率 | C22、A03 |
| [The Economist 官方选举模型](https://github.com/TheEconomist/us-potus-model) | 动态多层模型，民调模式/总体/非响应调整及州间相关 | 民调人数就是独立选举次数，或全国票份额就是胜选概率 | A03、B18、C25、C30、C34 |
| [ECMWF Forecast User Guide](https://confluence.ecmwf.int/spaces/FUG/pages/131397322/Forecast+User+Guide) | ensemble、明确定义时距/地点/事件及相应预报验证 | ensemble 次数是现实重复样本或单次天气验证一个概率 | A04、C27、C28、D44 |

选举案例说明：同一次选举的不同民调共享总体/方法偏差，州结果也有相关性；对投票份额建立分布后再计算胜选事件，不能把所有民调“成功”拼成一个 Jeffreys 计数。天气案例说明：模型成员表示预测分布的离散近似，真实 forecast-outcome 验证需地点、阈值与预报时距一致。这两类案例都支持“预测表现可跨事件积累”，而不是“事件语义可忽略”。
