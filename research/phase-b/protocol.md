# Phase B 比较协议

在查看本轮实验输出前固定以下问题、网格、对照、指标和停止依据。问题选择源于已接受的 Phase A [方法](../../docs/research/phase-a/methods-and-assumptions.zh-CN.md)、[交叉表](../../docs/research/phase-a/ledger-crosswalk.zh-CN.md)和[七项缺口](../../docs/research/phase-a/new-questions-and-gaps.zh-CN.md)。

| ID | Phase A 出发点和统一目标 | 事先固定的试验、判读和负对照 |
|---|---|---|
| B-E001 | A02/D41。稳定 iid 群体的固定风险 p 的区间 | 穷举 n=5,20,100，p=.0001,.001,.01,.05,.2,.5,.99，以及 p=0,1；比较 v1 中央 Jeffreys、均匀先验、Wilson、Clopper–Pearson 和 Wald 的覆盖与期望宽度；单列 v1 gate 概率。先比较同一个参数对象，再独立检查未来批次预测方差。 |
| B-E002 | B10/B15–B17/C23。单个已定义新目标群的 p | 固定三组历史 18/90/162 次事件、每组 180 次观察（两种历史设定：仅第一组或全三组）；给定已观察历史，对目标 n=0,4,20,100、p=.1,.3,.5 精确枚举；Jeffreys 不借、完整汇聚、固定幂折扣与先验混合；比较偏差、RMSE、参数区间覆盖、阈值 .25 的拒绝/决策损失。没有目标结果时单列先验预测和弃权。低维层级与经验 Bayes 的对照也由公共记录补充，不以此固定历史枚举认证组外泛化。 |
| B-E003 | B18/B19/B21、NEW-A-005。部署总体的标准化风险及估计误差 | 目标可见带层标签的单位，低/高层 p=.05/.45，目标高层权 .2，从平衡的分层调查估计风险；同一目标样本可同时贡献权与风险。另对不等权的风险构成制造共同受随机抽样的联合校验，并用配对重采样/全方差分析观察协方差项。在有簇的例子中比较按行和按簇的方差及覆盖。固定随机种子 57031，20,000 次，报告成对 Monte Carlo SE。缺支持用界，无外推。 |
| B-E004 | B13/C33、NEW-A-004。固定期绝对发生及标签识别 | 模拟两个原因与失访，均由可声明的离散时点机制发生；在独立失访和按潜在原因失访下比较 Aalen–Johansen、完成病例率、竞争事件删失后的 1−KM；用解析真值核对。不同目标只作为误用反例。测量误差界做解析。种子 57032，8,000 次，每次 200 单位。 |
| B-E005 | D35/D36、NEW-A-001/002/003/007。同题同期限预测评价 | 精确动态规划：iid 公平符号序列 n=20–200 连续监测，对比固定终点正态边界、相同边界窥视和有限并集 Hoeffding 边界。另用构造、可逐行显示的数据比较分组与总体 Brier、首发/终态、选择性可见真值，以及带弃权成本的全请求损失；这部分只验证反例，不拟合预测。 |
| B-E006 | D41/E48、NEW-A-006。相同 Beta CDF/PPF 和 v1 的结算门槛 | 固定四组半整数形状（小 n、强偏斜大计数、普通/转换切分附近、极端平衡）。生产 C 路径只读编译并通过小探针输出。与高精度独立密度积分或半整数递推比较。对相邻 binary64、相同数值编码和输入舍入前的精确有理阈值分别检查；给出参考精度加倍差、分位邻接和尾端差。 |
| B-E007 | B15/B16/C23。真实同一组成员未来打数命中率 | 用 Efron–Morris 的 18 名球员早期击球拟合、后续真实计数配对评价；比较独立 Jeffreys、公共率、EB 以及小网格层级 Bayes；对相同未来打数加权 Brier/log loss，附等球员权和留单球员评分敏感性；不以赛季内回测证明新球员或跨赛季校准。 |

B1 覆盖其余问题时，先指定端点、可用性时钟和目标；特征预测、分布预测、专家信念、联合事件、损失和数值误差按对象区分。没有合格标签的新设备、无法查见的选择机制及任意平台数值保证不能靠模拟解决。优先保留简单对照或明确弃权。若数据源或数值预算导致协议变动，保留原因与新范围。若配对差不超过 Monte Carlo 误差则保留不确定。完成标准是所有对象覆盖并有可重跑的关键比较、逆向反例和直接可核对引用。
